#  AI Laboratory Assistant using RAG System

An AI-powered Laboratory Assistant built using RAG (Retrieval-Augmented Generation) architecture.  
The system allows users to upload laboratory PDF reports and ask AI-based questions from uploaded documents.

---

#  Features

- Upload laboratory PDF reports
- Extract report text automatically
- Generate embeddings using Sentence Transformers
- Store vectors in FAISS vector database
- Ask questions from reports
- AI-generated contextual answers using Gemini API
- Interactive frontend using Streamlit
